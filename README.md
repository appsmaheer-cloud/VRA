# PNS Enterprise - VRA, Fuel & Fleet Performance Dashboard
## Single Page Application (SPA) with AJAX & Google Apps Script Cloud Engine

Dashboard analitik armada, konsumsi BBM, servis pemeliharaan, dan simulasi biaya operasional PT Pratama Nusantara Sakti.

### Keunggulan Versi Ini:
- **100% Identik (Full Parity):** Tampilan, menu sidebar, kartu KPI interaktif, dan grafik sama persis dengan versi server lokal Laragon.
- **Tanpa Reload Halaman (SPA):** Transisi antar view (Overview, Armada VRA, BBM, Servis, Simulasi) terjadi secara instan dalam memori.
- **AJAX Asynchronous Data Fetching:** Data ditarik di latar belakang via API tanpa jeda loading halaman.
- **Dukungan Multi-Source:** Dapat membaca data langsung dari cache cloud statis dan/atau live dari Google Sheets via Google Apps Script Web App API URL.
